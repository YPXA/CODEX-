# Chinese LaTeX report project

Compile with XeLaTeX/LuaLaTeX and latexmk. Default fonts: SimSun, SimHei, Times New Roman and Cambria Math.

For portable compilation, create font-profile.tex containing \portablefontstrue. This uses open TeX Live fonts, a different typography profile.

GitHub Actions selects portable fonts and uploads the PDF artifact. Equations use actual math layout. Keep real scientific statements and data traceable to their sources. This is a typesetting demonstration, not experimental evidence.
