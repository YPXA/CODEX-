# Git collaboration

Commit main.tex, section files, figures, bibliography and styles. Exclude build products, font-profile.tex, caches and machine-specific configuration.

The template uses xu-cheng/latex-action, XeLaTeX and TeX Live 2026. Action refs are pinned to verified SHAs. On push, pull request or manual dispatch, the workflow builds and uploads a PDF artifact. It does not publish a site or commit PDFs.

CI explicitly uses portable fonts. Exact Windows typography requires separately authorized licensed font provisioning; do not upload Windows font files.

For teamwork use branches, section files when useful, pull-request review and the successful run's PDF artifact. WebLaTex/Codespaces can be evaluated separately; do not start billable environments automatically.

## Memory export

Sync only explicitly authorized preference notes and skill files. The full memory directory is not an export source. Public exports omit names, school/project records, user-specific paths, raw chats, credentials, machine logs and private papers. Record the remote commit and verify its file list.

Recurring synchronization is a separate request.
